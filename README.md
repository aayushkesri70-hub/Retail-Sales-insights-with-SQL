📊 E-Commerce SQL Data Analysis Project
📌 Overview

This project focuses on analyzing an e-commerce dataset using SQL to extract meaningful business insights. The database is designed using multiple related tables and queries are written to evaluate customer behavior, sales trends, product performance, and payment patterns.

🗂️ Database Schema

The project consists of the following tables:

Customers – Customer details
Products – Product information and pricing
Orders – Order records and status
Order_Items – Product-level order details
Payments – Payment transactions
🧠 Key Business Problems Solved

This project goes beyond basic SQL and focuses on real-world analysis:

🔹 Customer Analysis
Customer Lifetime Value (CLV)
Repeat Purchase Rate
Top 5 Highest Paying Customers
Customers with No Orders

🔹 Sales & Revenue Analysis
Total Revenue by Payment Mode
Month-wise Sales Trend
Average Order Value (AOV)
High-Value Orders

🔹 Product Analysis
Most Sold Products
Top Products by Revenue
Products Never Ordered
Category-wise Price Analysis

🔹 Payment Insights
Most Used Payment Method
COD vs Online Payment %
Payment Trends (UPI vs Card)

⚙️ SQL Concepts Used
Joins (INNER JOIN, LEFT JOIN)
Aggregations (SUM, AVG, COUNT)
GROUP BY & HAVING
Subqueries
Window Functions
CASE Statements
Date Functions (Monthly Analysis)


📈 Sample Insights
Identified top customers contributing maximum revenue
Analyzed customer retention using repeat purchase rate
Detected unsold inventory and low-performing products
Compared digital vs cash payment adoption trends

🚀 How to Use
Create the database using provided table schemas
Insert the sample data
Run SQL queries from the analysis section
Modify queries to explore additional insights
